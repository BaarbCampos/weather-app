# 🌦️ Weather App

A modern weather application built with **Next.js** and **Tailwind CSS**, using the **Open-Meteo API** to display real-time weather data in a clean and responsive interface.

---

## ✨ Features

- 🔎 Search weather by city name
- 🌡️ Current weather conditions
- 📊 Detailed weather information (wind, humidity, temperature)
- 📅 Weekly forecast
- ⏱️ Hourly forecast
- 📱 Fully responsive design (mobile, tablet, desktop)

---

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Open-Meteo API
